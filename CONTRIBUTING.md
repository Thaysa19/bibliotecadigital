# Guia de Contribuicao

## Como contribuir

### 1. Clone o repositorio
git clone git@github.com:Thaysa19/bibliotecadigital.git

### 2. Crie uma branch para sua alteracao
git checkout -b minha-alteracao

### 3. Faca suas alteracoes e commit
git add .
git commit -m "descricao clara da alteracao"

### 4. Envie para o GitHub
git push origin minha-alteracao

### 5. Abra um Pull Request
- Acesse o repositorio no GitHub
- Clique em "Compare & pull request"
- Descreva as alteracoes feitas
- Clique em "Create pull request"

## Boas praticas de commits

Use mensagens claras e objetivas. Exemplos:
- feat: adiciona funcao de busca
- fix: corrige erro ao remover arquivo
- docs: atualiza documentacao
