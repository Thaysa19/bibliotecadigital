# Biblioteca Digital - PUCPR

Sistema de gerenciamento de documentos digitais desenvolvido em Python.

## Funcionalidades

- Listar documentos por tipo (PDF, EPUB, Outros)
- Listar documentos por ano de publicacao
- Adicionar novos documentos
- Renomear documentos existentes
- Remover documentos

## Estrutura do Projeto

bibliotecadigital/
    documentos/
        pdf/
        epub/
        outros/
    testes/
    biblioteca.py
    CONTRIBUTING.md
    README.md

## Como executar

1. Clone o repositorio:
git clone git@github.com:Thaysa19/bibliotecadigital.git

2. Entre na pasta:
cd bibliotecadigital

3. Execute o sistema:
python biblioteca.py

## Requisitos

- Python 3.x
